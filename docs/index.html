Improving the efficiency and performance of satellite research software

Our project focuses on optimizing the performance of satellite research software, specifically targeting the processing of GNSS (Global Navigation Satellite System) data. By implementing advanced algorithms and leveraging parallel computing techniques, we aim to significantly reduce the time required for data analysis while maintaining accuracy and reliability. This will enable researchers to process larger datasets more efficiently, ultimately accelerating scientific discoveries in the field of satellite navigation and geospatial analysis.

What it does

Key Features

Our tool allows you to easily convert RINEX files into a structured database format. It parses both observation and navigation files, and calculates precise positions, azimuth, and elevation data. The software is designed to handle large datasets efficiently, making it ideal for researchers working with extensive GNSS data.

Easy RINEX File Conversion

Convert RINEX files into a structured database format with just a few commands.

Efficient GNSS Data Processing

Our tool simplifies the process of handling GNSS data, allowing you to focus on analysis rather than data preparation.

Real-time Data Visualization

Visualize GNSS data in real-time, enabling researchers to monitor and analyze satellite positions and movements as they occur.

Try it yourself

How to Run the Project

RNX2DB runs locally on Windows, macOS, or Linux. You'll need Python 3.8+ installed.

  1. 1

    Clone the repository

    Download the project to your machine using Git, or use the "Download ZIP" button on GitHub and extract it.

    git clone https://github.com/KathrynJButler/optimizing-research-software-codes.git
    cd optimizing-research-software-codes/gnss_python-main

  2. 2

    Create a virtual environment

    This keeps the project's dependencies isolated from the rest of your Python installation.

    python -m venv rnx2db_env

    Then activate it:
    Windows: rnx2db_env\Scripts\activate
    macOS / Linux: source rnx2db_env/bin/activate

  3. 3

    Install dependencies

    With your virtual environment active, install all required packages in one command.

    pip install -r requirements.txt

    If you see any cache errors, run pip cache purge first.

  4. 4

    Configure your input files and run

    Open config.yaml and enter the paths to your RINEX files in the observation and navigation fields. Then run:

    python rnx2db.py

    For multiday processing, set multiday.enabled: true in config.yaml and point obs_location at your data directory.

Requirements: Python 3.8+, Windows / macOS / Linux. VS Code users: the Python extension will detect your rnx2db_env virtual environment automatically. For a more detailed walkthrough, see the full setup guide →
